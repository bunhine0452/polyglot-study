10개 언어를 개별 트랙으로 학습하는 macOS 네이티브 앱. 학습자가 쓴 코드를 그 사람 맥에서 실제로 실행하고 채점하며, FSRS-6 로 복습을 스케줄합니다.

설치

내려받아 압축을 풀고 Polyglot.app 을 응용 프로그램 폴더로 옮긴 뒤 그냥 열면 됩니다. 이 빌드는 Apple Developer ID 로 서명하고 애플 공증(notarization)을 거쳤으므로 Gatekeeper 경고가 뜨지 않습니다 — 우회 절차도, 터미널 명령도 필요 없습니다.

공증 티켓이 앱에 스테이플돼 있어 인터넷이 끊긴 맥에서도 온라인 조회 없이 열립니다. 앱 안의 자동 업데이트는 그와 별개로 EdDSA 서명이 검증합니다.

알파입니다

동작하는 것과 아직 아닌 것을 정직하게 적습니다.

  • 됩니다 — 온보딩·대시보드·트랙·레슨·에디터+콘솔·복습 여섯 화면. 과제 블록에서 에디터로 들어가 코드를 쓰고 실행·채점까지 갑니다. Swift 는 코드 완성과 인라인 진단도 됩니다.
  • 아직입니다 — 공증(위 참고), 나머지 7개 트랙의 콘텐츠, Assembly 레지스터 패널.
