@Concept(id: concept) {
프로그램이 세상과 처음으로 대화하는 방법은 화면에 글자를 출력하는 것입니다. 파이썬에서는 print() 함수가 그 역할을 맡습니다. 함수란 이름 뒤에 괄호를 붙여 호출하면 정해진 일을 수행하는 코드 묶음인데, print() 는 파이썬에 기본으로 들어 있어서 따로 설치할 필요가 없습니다. print("안녕") 처럼 괄호 안에 값을 전달하면 그 값이 화면에 나타나고, 출력이 끝나면 자동으로 줄을 바꿉니다.

따옴표로 감싼 값은 문자열 리터럴이라고 부릅니다. 리터럴이란 코드에 그대로 적힌 값이라는 뜻입니다. 문자열은 큰따옴표("...")나 작은따옴표('...') 어느 쪽으로도 감쌀 수 있고, 두 표기는 완전히 같은 의미입니다. 따옴표 안의 내용은 파이썬이 해석하지 않고 글자 그대로 다룹니다. 따옴표가 없는 3 은 숫자 값이지만, "3" 은 글자로 이루어진 문자열이라는 점이 다릅니다.

print() 의 괄호 안에 값을 여러 개 전달하려면 쉼표로 구분합니다. 이때 파이썬은 값들을 한 줄에 이어 출력하면서 값 사이에 공백을 자동으로 하나씩 넣어 줍니다. print("a", "b", "c") 는 a b c 를 출력합니다. 자동으로 들어가는 이 공백은 초반에 의외한 결과를 만들기도 하니, 직접 실행해 보면서 감각을 익히는 것이 좋습니다.

# 기호로 시작하는 줄은 주석입니다. 파이썬은 한 줄에서 # 뒤에 오는 내용을 아예 무시하고 실행하지 않기 때문에, 주석은 실행 결과에 아무런 영향을 주지 않습니다. 대신 코드를 읽는 사람에게 이유나 의도를 설명하는 메모로 쓰입니다. 코드를 잠시 꺼 두고 싶을 때 해당 줄 앞에 # 를 붙이는 방법도 자주 씁니다.

마지막으로 REPL 을 알아 두면 연습이 쉬워집니다. REPL 은 Read-Eval-Print Loop 의 약자로, 입력한 한 줄을 읽고(Read) 실행하여(Eval) 결과를 출력하고(Print) 다시 입력을 기다리는(Loop) 대화형 실행 환경입니다. 파이썬을 실행하면 나타나는 >>> 프롬프트가 바로 REPL 이며, 여기에 print("hello") 를 입력하면 즉시 hello 가 출력됩니다. 긴 프로그램은 파일로 작성하고, 짧은 실험은 REPL 로 확인하는 습관이 앞으로의 학습을 훨씬 빠르게 만들어 줍니다.
}
