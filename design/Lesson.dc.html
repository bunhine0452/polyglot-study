복사되는 값, 공유되는 참조

구조체는 대입할 때 복사되고, 클래스는 같은 인스턴스를 가리키는 참조가 넘어갑니다. 실행해서 두 print 의 결과가 왜 다른지 확인하세요.

struct Point { var x = 0 }
final class Box { var x = 0 }

var p1 = Point(); var p2 = p1      // 복사
p2.x = 10
print(p1.x, p2.x)                  // 0 10

let b1 = Box();   let b2 = b1      // 참조 공유
b2.x = 10
print(b1.x, b2.x)                  // 10 10
