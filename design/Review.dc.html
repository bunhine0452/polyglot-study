질문
let 으로 선언한 struct 인스턴스의 저장 속성을 바꿀 수 있습니까? class 인스턴스라면요?
답

struct 는 바꿀 수 없습니다 — 값 타입은 let 으로 인스턴스 전체가 불변이 됩니다. class 는 바꿀 수 있습니다 — let 은 참조만 고정하고, 참조가 가리키는 인스턴스의 속성은 여전히 변경할 수 있습니다.

let p = Point(x: 1)
p.x = 2        // 컴파일 오류: 'p' is a 'let' constant
let b = Box(x: 1)
b.x = 2        // 가능 — 참조는 그대로, 속성만 바뀜
