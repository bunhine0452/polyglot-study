Polyglot Study ALPHA

10개 언어를 개별 트랙으로 학습하는 macOS 네이티브 앱. 학습자가 쓴 코드를 그 사람 맥에서 실제로 실행하고 채점하며, FSRS-6 로 복습을 스케줄합니다.

지금 배울 수 있는 것파이썬 첫걸음 24편 · SQL 기초 22편 · Swift 첫걸음 24편 (총 70편)
나머지 7트랙은 앱에서 "준비 중" 으로 보입니다.
요구 사양macOS 14 이상 · Apple Silicon
툴체인Python 은 python3, Swift 는 Xcode 툴체인이 필요합니다. SQL 은 앱에 내장돼 있어 따로 설치할 것이 없습니다.
앱의 툴체인 화면이 무엇이 있고 무엇이 없는지 진단해 줍니다.

처음 열 때 — Gatekeeper

이 알파는 Apple Developer ID 인증서 없이 ad-hoc 서명돼 있어, 처음 실행하면 macOS 가 "Apple은 악성 코드가 없음을 확인할 수 없습니다" 라며 막습니다. "휴지통으로 이동" 을 누르지 마시고 "완료" 를 누른 뒤, 아래 둘 중 하나로 여십시오.

방법 1 — 시스템 설정

  1. 앱을 한 번 실행해 위 대화상자를 띄우고 완료를 누릅니다.
  2. 시스템 설정 → 개인정보 보호 및 보안 을 열고 아래로 스크롤합니다.
  3. "Polyglot.app"이(가) 차단되었습니다 옆의 그래도 열기 를 누릅니다.
  4. Touch ID 나 암호로 확인하면 열립니다. 이 뒤로는 그냥 열립니다.

방법 2 — 터미널 한 줄 (앱을 옮겨 둔 경로로 바꾸세요)

xattr -dr com.apple.quarantine /Applications/Polyglot.app

macOS 15 이상에서는 "우클릭 → 열기" 가 통하지 않습니다. Apple 이 그 우회 경로를 없앴습니다 — 예전 안내를 보셨다면 위 방법을 쓰십시오.
인증서(Apple Developer Program, 연 $99)를 확보하면 공증을 붙여 이 단계가 완전히 사라집니다. 앱 안의 자동 업데이트는 지금도 EdDSA 서명으로 검증되므로 이 문제와 무관합니다.

알파입니다

동작하는 것과 아직 아닌 것을 정직하게 적습니다.
